Demand can wobble

Five scenarios are created around each nominal demand value. CV controls how wide that wobble is.

Short queues cost less

E[(D - n)⁺] = Σᵥ pᵥ max(v - n, 0) measures the average unmet demand at staffing level n.

3

QAE checks the expectation

Probabilities and shortfall are encoded as amplitudes. This app evaluates the noiseless payoff amplitude analytically.

4

VQE is an optional solver view

The QUBO can become an Ising Hamiltonian for VQE. This build shows that mapping clearly, but uses a deterministic exact reference solver.
